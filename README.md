## 🌟 Projects

### 1. ✔️ Basic Calculator
A simple calculator script that performs basic arithmetic operations.

**File:** `calculator.py`  
**Features:**  
- Addition
- Subtraction
- Multiplication
- Division

---

### 2. 📅 To-Do List Manager
A command-line tool to manage tasks efficiently.

**File:** `todo_list.py`  
**Features:**  
- Add tasks
- Remove tasks
- View tasks
- Mark tasks as completed
- Clear all tasks

---

### 3. 🌡️ Temperature Converter
Easily convert temperatures between Fahrenheit and Celsius.

**File:** `temperature_converter.py`  
**Features:**  
- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius

---

### 4. 🔑 Random Password Generator
Generate secure passwords with customizable settings.

**File:** `password_generator.py`  
**Features:**  
- Customizable password length
- Includes letters, digits, and special characters

---

### 5. 🎮 Tic Tac Toe Game
A fun Tic Tac Toe game for two players or against an AI opponent.

**File:** `tic_tac_toe.py`  
**Features:**  
- Play against another player or the computer
- Basic AI for the computer opponent
